 DSA Visualizer

DSA Visualizer is a web application built using React.js and JavaScript to help users learn Data Structures and Algorithms through interactive visualizations. It shows how different algorithms work step by step, making them easier to understand.

   Features

- Sorting Visualizer
  - Bubble Sort
  - Selection Sort
  - Insertion Sort
  - Merge Sort
  - Quick Sort
- Searching Visualizer
  - Linear Search
  - Binary Search
- Stack Visualizer
- Queue Visualizer
- Linked List Visualizer
- Binary Search Tree (BST)
- Graph Traversal (BFS & DFS)
- Dark and Light Theme
- Animation Speed Control
- Time and Space Complexity
- Responsive Design

 Tech Stack

- React.js
- JavaScript
- HTML
- CSS
- React Router
- Vite

  How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/dsa-visualizer.git
```

2. Go to the project folder

```bash
cd dsa-visualizer
```

3. Install dependencies

```bash
npm install
```

4. Start the project

```bash
npm run dev
```

5. Open your browser and visit:

```
http://localhost:5173
```
